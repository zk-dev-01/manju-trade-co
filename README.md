## Overview
A themed front-end web application inspired by a merchant trading system. 
Users can browse goods, view character reviews, and interact with a dynamic cart interface within a fully customized UI.

## Tech Stack
- HTML
- CSS
- JavaScript

## Features
- Dynamic display of trade goods and categories
- Character-based review section
- Interactive add-to-cart system
- Responsive layout with custom styling and animations

## What I Learned
- Structuring multi-section web pages using HTML
- Designing and customizing UI with CSS
- Adding interactivity with JavaScript (event listeners, DOM manipulation)
- Working with external assets and integrating them into a cohesive design

## Notes
This project focuses on front-end design and interaction, with an emphasis on theming, layout, and user experience.

## Future Improvements

- Add backend support for real transactions
